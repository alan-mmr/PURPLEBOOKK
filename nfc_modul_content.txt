Modul 11Web NFC API01PENGANTAR WEB NFC API1.1  Apa itu Web NFC API?Web NFC API adalah antarmuka JavaScript standar yang memungkinkan halaman web membaca dan menulis tag NFC (Near Field Communication) secara langsung dari browser tanpa memerlukan aplikasi native. API ini merupakan bagian dari inisiatif Project Fugu milik Google, yaitu program perluasan kemampuan web platform agar setara dengan native app.NFC (Near Field Communication) adalah teknologi komunikasi nirkabel jarak sangat pendek (≤ 4 cm) yang beroperasi pada frekuensi 13,56 MHz. Teknologi ini lazim digunakan pada kartu akses, kartu identitas, sistem pembayaran contactless, dan aset tracking.📌  Catatan Penting — Kompatibilitas BrowserWeb NFC API HANYA berfungsi di Android Chrome versi 89 ke atas.iOS Safari: TIDAK didukung (Apple membatasi akses NFC untuk aplikasi pihak ketiga).Desktop Chrome: TIDAK ada hardware NFC — API tersedia di kode tetapi tidak fungsional.Firefox dan browser lain: Tidak didukung.Solusi praktikum: Gunakan smartphone Android peserta sebagai perangkat scanner.1.2  Cara Kerja Web NFC APIWeb NFC API bekerja melalui antarmuka NDEF Reader (NFC Data Exchange Format Reader). Alur kerja dasar adalah sebagai berikut:LangkahAksiKeterangan1User klik tombol di halaman webWajib ditrigger dari gestur pengguna (user gesture)2Browser minta izin NFCMuncul popup permission di Android3NDEFReader.scan() dipanggilNFC hardware diaktifkan, siap membaca4Kartu NFC didekatkan ke HPJarak ≤ 4 cm, biasanya di bagian belakang HP5Event 'reading' terpanggilData tag tersedia: serialNumber + records6JavaScript memproses dataKirim ke backend Laravel via fetch/axios7Backend meresponsValidasi, contoh simpan ke DB lalu kembalikan respons1.3  Struktur Data Tag NFC (NDEF)Saat tag NFC dibaca, data dikembalikan dalam format NDEF (NFC Data Exchange Format). Struktur yang perlu dipahami:// Struktur respons NDEFReader{  serialNumber: "04:AB:CD:EF:12:34:56",   // ID unik tag NFC  message: {    records: [                              // Bisa berisi 1 atau lebih record      {        recordType: "text",                // Tipe: text, url, mime, dll.        mediaType: "text/plain",        data: ArrayBuffer,                 // Raw bytes        encoding: "UTF-8",        lang: "en"      }    ]  }}1.4  Persyaratan TeknisSyaratDetailAlasanHTTPS atau localhostURL wajib menggunakan protokol amanKebijakan keamanan browser ChromeUser GestureNDEFReader.scan() hanya bisa dipanggil setelah klik/tap userMencegah akses NFC secara diam-diamPermission NFCUser harus grant izin secara eksplisitPrivacy & security model AndroidAndroid Chrome ≥ 89Versi minimum yang mendukung APIBaru diimplementasi mulai versi iniHardware NFCTidak semua HP Android punya chip NFCVerifikasi di Settings → Connections02DEBUGGING & REMOTE INSPECTIONSalah satu tantangan utama mengembangkan fitur NFC adalah bahwa testing harus dilakukan di perangkat fisik (smartphone), bukan di emulator. Ada dua metode yang umum digunakan untuk mendebug kode yang berjalan di HP dari laptop developer.2.1  Metode 1 — Chrome Remote Debugging via USB (Disarankan)Metode ini memungkinkan DevTools di laptop terhubung langsung ke Chrome yang berjalan di smartphone via kabel USB. Seluruh fitur DevTools tersedia: Console, Network, Sources, Breakpoints, dan Application.ARSITEKTUR REMOTE DEBUGGING[ HP Android ]  ←── Kabel USB ──→  [ Laptop Developer ]    Chrome Mobile                      Chrome DevTools  (scan NFC fisik)            (console, breakpoint, network)Langkah-langkah Setup Remote DebuggingLangkah A — Persiapan di HP AndroidBuka Settings → About Phone → ketuk Build Number sebanyak 7 kali hingga muncul notifikasi 'You are now a developer!'Masuk ke Settings → Developer Options → aktifkan USB Debugging (geser toggle ke ON).Hubungkan HP ke laptop menggunakan kabel USB (gunakan kabel data, bukan kabel cas biasa).Pada popup di HP yang bertuliskan 'Allow USB debugging?', pilih Allow. Centang 'Always allow from this computer' jika ingin permanen.Buka Chrome di HP, navigasikan ke URL aplikasi Laravel Anda (misal: http://10.0.0.5:8000 atau URL yang dapat diakses dari jaringan lokal yang sama).Langkah B — Setup di LaptopBuka Chrome di laptop, ketik di address bar: chrome://inspect/#devices kemudian tekan Enter.Pastikan checkbox 'Discover USB devices' sudah dicentang.HP Anda akan muncul di daftar dengan nama model dan serial number.Di bawah nama HP, akan tampil daftar tab Chrome yang sedang terbuka di HP.Klik tombol inspect di samping tab yang menjalankan aplikasi NFC Anda.Jendela DevTools baru akan terbuka di laptop — ini adalah DevTools dari Chrome yang berjalan di HP secara real-time.✅  Apa yang bisa dilakukan setelah terhubung?Console: Semua console.log() dari kode di HP tampil di laptop secara live.Sources: Pasang breakpoint — kode di HP akan berhenti di baris tersebut.Network: Monitor request/response fetch() ke backend Laravel.Application: Lihat localStorage, sessionStorage, Service Worker.Elements: Inspect dan edit DOM secara langsung.Saat HP melakukan scan NFC fisik, semua event dan log muncul di DevTools laptop.2.2  Metode 2 — Wireless via ngrok + Port ForwardingMetode ini cocok ketika tidak ingin atau tidak bisa menggunakan kabel USB, misalnya saat demo kepada peserta dari jarak jauh atau ketika backend berjalan di mesin yang berbeda.Opsi A — ngrok (Tunnel Public HTTPS)ngrok membuat tunnel dari localhost laptop ke URL publik HTTPS. Karena Web NFC API wajib HTTPS, ini solusi yang sangat praktis untuk testing cepat.# 1. Install ngrok (sekali saja)npm install -g ngrok# atau download dari https://ngrok.com/download # 2. Jalankan Laravel development serverphp artisan serve --port=8000 # 3. Buat tunnel ngrok ke port 8000ngrok http 8000 # Output ngrok:# Forwarding  https://abc123.ngrok.io  ->  http://localhost:8000 # 4. Buka URL ngrok di HP Android Chrome# https://abc123.ngrok.io# Web NFC API langsung bisa digunakan karena sudah HTTPS!Opsi B — Chrome DevTools Port Forwarding (USB tetap diperlukan)Alternatif tanpa ngrok: HP dan laptop cukup tersambung USB. Port Forwarding membuat HP seolah punya localhost sendiri yang mengarah ke laptop.Sambungkan HP ke laptop via USB (USB Debugging aktif, seperti Metode 1).Buka chrome://inspect/#devices di laptop.Klik tab Port forwarding → centang Enable port forwarding.Tambahkan aturan: Port 8000 → localhost:8000, klik Done.Di HP, buka Chrome dan akses http://localhost:8000 — ini akan diteruskan ke server Laravel di laptop.Karena menggunakan localhost, Web NFC API tetap dapat berfungsi tanpa HTTPS.2.3  Perbandingan Kedua MetodeAspekRemote Debugging (USB)ngrok / Port ForwardingKoneksiKabel USBWiFi / Tunnel internetHTTPSTidak wajib (via localhost)ngrok otomatis HTTPSKecepatanSangat cepat, stabilBergantung koneksi internetDevToolsFull DevTools di laptopInspect via URL ngrok (terbatas)SetupButuh aktifkan Developer ModeInstall ngrok, lebih mudahCocok untukDevelopment & debugging intensifDemo, testing cepat, remoteBiayaGratis penuhGratis (ngrok free tier terbatas)03STUDI KASUS — SISTEM ABSENSI NFCBuatlah sebuah sistem absensi berbasis NFC menggunakan Laravel sebagai backend dan Web NFC API sebagai scanner di browser mobile. Mahasiswa membawa kartu NFC yang telah terdaftar; dosen atau petugas mendekatkan kartu ke HP untuk mencatat kehadiran. Silahkan anda buat disain DBnya secara mandiri.3.1  Contoh simple code implementasi NFC<!DOCTYPE html><html lang="id"><head>    <meta charset="UTF-8">    <meta name="viewport" content="width=device-width, initial-scale=1">    <title>NFC Scanner</title></head><body>    <h2>NFC Scanner</h2>    <button onclick="startScan()">Aktifkan NFC</button>    <p id="status">Belum aktif.</p>    <div id="hasil"></div>    <script>        async function startScan() {            if (!('NDEFReader' in window)) {                document.getElementById('status').textContent = 'Browser tidak mendukung Web NFC.';                return;            }            try {                const ndef = new NDEFReader();                await ndef.scan();                document.getElementById('status').textContent = 'NFC aktif. Dekatkan kartu...';                ndef.addEventListener('reading', ({ serialNumber, message }) => {                    let isi = '';                    for (const record of message.records) {                        isi += new TextDecoder().decode(record.data);                    }                    //untuk test debug di laptop                    console.log('Serial:', serialNumber);                    console.log('Jumlah record:', message.records.length);                    console.log('Isi:', isi);                    document.getElementById('hasil').innerHTML =                        '<p><b>Serial:</b> ' + serialNumber + '</p>' +                        '<p><b>Isi:</b> ' + (isi || '(kosong)') + '</p>';                });            } catch (err) {                document.getElementById('status').textContent = 'Error: ' + err.message;            }        }    </script></body></html>04REFERENSI & EKSPLORASI LANJUTANBerikut adalah
